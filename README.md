# 🚀 Programming Problems

Welcome! This repository contains solutions to programming problems from platforms such as **LeetCode**, **HackerRank**, **Codeforces**, and more.

All solutions are currently written in **C++**, but the structure is ready to include other languages like **Python**, **Java**, etc.

If you'd like to contribute and help others learn, you're more than welcome to open a pull request! 🙌

---
